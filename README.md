# 《贡献纪元：新文明的操作系统——从万物资本到贡献主义》

**全书中文版**

---

《贡献纪元：新文明的操作系统——从万物资本到贡献主义》是一部完整的文明转型蓝图。它从哲学根基出发，重新定义资本、善恶与理性，设计了一套以“贡献值”为核心的社会操作系统，并提供了从今天就可以开始的实践路径。全书25万字，五篇环环相扣：诊断→批判→建构→实践→愿景。
